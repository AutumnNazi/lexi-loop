# Lexi Loop

[![Dev release](https://github.com/AutumnNazi/lexi-loop/actions/workflows/dev-release.yml/badge.svg)](https://github.com/AutumnNazi/lexi-loop/actions/workflows/dev-release.yml)

界面采用墨绿与奶白的学习手账风格。应用图标、16 个页面图标和学习插画均由 magpie-image 生成；素材与提示词保存在 `assets/source/`，切图、透明背景处理和四端尺寸转换由 `scripts/generate_icons.py` 复现（需要 Pillow，仅供开发时处理图片）。

Lexi Loop 是一个离线优先的 Flutter 背词应用，围绕「先回忆，再揭晓，再评分」建立学习循环。复习日期由 FSRS-6 安排，记忆曲线展示遗忘与复习强化的估计趋势。项目已生成 Windows、macOS、Android、iOS 平台工程；各端实际验证范围见下文。

应用数据保存在本机 SQLite，内置 CET4、CET6、专八、考研及「日常微光」5 本词书，共 13,165 个去重词义、13,141 个去重单词。考试词库从用户提供的打包词表离线导入，释义与音标来源于 ECDICT，不含例句，也不代表考试官方发布的年度大纲。需求来源为 `prompt.md`，本文以当前代码、锁定依赖和实际验证结果为准。

## 功能

| 功能 | 当前行为 |
| --- | --- |
| 今日任务 | 显示全部到期词义数、今日新词义目标与完成数、所选词书的已学进度、连续学习天数、近 7 天回忆成功率。队列为空时直接说明每日目标为 0、今日新词额度已用完或当前范围暂无新词，并显示当前范围的下一次复习时间。 |
| 词义回忆 | 先展示单词，点击「回忆」揭晓释义，再用 Again / Hard / Good / Easy 评分；评分前展示各档预计间隔。 |
| 撤销与小结 | 当前页面保留最近一次成功评分的「撤销上一评分」，下一张卡与空队列均可用；撤销会原子恢复该评分前状态或删除首学记忆状态，并删除对应评分事件。本轮小结按真实存在且未撤销的评分统计次数、首学词义数、复习次数和 Good+Easy 成功率；离开页面即结束。 |
| 学习词书 | 首页可固定内置或自建词书，选择随本地设置保存，重启和备份恢复后沿用；选择“全部词书”可解除限制。首页拼写练习也使用当前词书。 |
| 复习队列 | 首页优先处理全部已学且 `due <= now` 的到期词义，包括已不再属于任何词书的孤立词义；新词只从所选词书加入；每日额度在所有词书间共用，换书不重置。词书页或指定词义发起的学习仍限定各自范围。评分后刷新队列，空队列会区分「每日目标为 0」「额度耗尽」「当前范围无未学词」「当前无到期词」，并显示对应范围的下一次复习时间或间隔。 |
| 词书与词条 | 按词书浏览，搜索英文单词或中文释义，查看例句、记忆阶段、下次复习时间与该词义的曲线。支持全部、未学、已学、待复习四种状态筛选；筛选与词书、搜索、分页组合，条数使用同一套 SQLite 过滤规则。 |
| 离线考试词书 | 内置大学英语四级 3,849 条、六级 5,407 条、英语专业八级 12,694 条、考研英语 4,801 条；四本词书共用 13,141 个单词，重复词条沿用同一记忆进度。词书列表每次加载 40 条，可继续加载或搜索完整词书。 |
| 自建词书 | 按来源词书筛选、搜索英文或中文释义，每页 40 条；跨搜索和页码保留勾选，可切换已选列表检查与取消。填写 1–40 字名称创建词书，同一词义跨词书共享进度。创建后可改名、增删词义；删除仅移除词书及选词关联，保留词条、记忆状态和评分历史，并在同一事务中清除指向该词书的首页学习选择。内置词书不能编辑或删除。 |
| 自定义词库导入 | 词书页独立入口，支持 CSV、TSV、TXT、JSON、JSONL 和词库包同款 JSONL `terms.dat`；支持 Anki Notes in Plain Text 与 Quizlet 粘贴文本。先解析预览，再确认写入；有错误行时禁止导入。整本词书、新词、新词义和关联在同一事务中创建，复用精确拼写与释义相同的已有进度，不覆盖已有例句/音标。 |
| 词书导出与迁移 | 单本词书可导出 CSV 或 JSON，仅包含词条内容，不含学习进度、评分历史或设置；CSV 使用 UTF-8 BOM 与标准引号转义。导入页提供 CSV/JSON 模板与格式说明。导出再导入会按现有词形/释义去重并复用进度。 |
| 统计 | 显示今日评分次数、累计评分次数、回忆成功率、连续学习天数、最近 7 天活动图及未来 7 天复习量预览。预览按本地日历聚合当前用户全部已学词义，不含新词、不受当前新词书过滤，孤立已学词仍计入。通过可搜索的分页列表从已学词义中选择曲线，不再一次性加载全部已学词；恢复或刷新后若原选择失效会回退，不混用旧曲线。 |
| 拼写练习 | 在数据库中从所选词书随机抽取最多 10 个去重单词，仅加载本轮题目；忽略答案首尾空白和大小写，只在本轮统计对错。完成页列出本轮错词，可仅重练错词或重新随机一轮；全部正确时不显示重练错词入口，重练会清空上一轮索引、正确数和答案。 |
| 外观主题 | 墨绿奶白、海盐蓝、暖杏棕、石墨灰四套完整深浅配色；每套可跟随系统、强制浅色或深色。设置页提供色卡预览，点击后写入 `app_settings` 并全局立即应用；重启保留，旧备份缺少主题键时默认墨绿跟随系统。 |
| 设置与备份 | 每日新词义目标可设为 0–100，默认 10；设为 0 后只安排已学内容的复习。通过系统文件选择器导出或恢复 JSON；恢复后同步刷新主题与所有页面。 |
| 学习快捷键 | Space / Enter 揭晓；无语义修饰键的 1–4 评分；Ctrl / Cmd + Z 撤销最近一次评分。弹窗/菜单打开或文本输入获得焦点时不抢占按键；按键连发、加载、错误、时钟倒退或忙碌时不触发评分。 |
| 自动刷新 | 启动、卡片到期、本地午夜、切换页面及应用回到前台时刷新；也可手动刷新。 |
| 自适应布局 | 宽度达到 760 时使用侧边 NavigationRail，否则使用底部 NavigationBar；支持中文界面与系统字号缩放。 |

学习单位是**词义**，记忆状态按「用户 × 词义 × 训练方式」唯一确定。今日新词目标按首次学习的词义计数；整体进度按去重单词计数，单词任一词义已学即计入已学单词。首页选定词书后，仅该书收录的词义已学才计入本书进度；同拼写但不同释义不混算。固定词书只限制新词来源，所有已学到期词义仍会复习；即使某条已学词义已不再属于任何词书，也不会从首页复习队列漏掉。今日完成数和活动图统计的是评分次数，同一个词义当天多次评分会分别计数。

成功率 = `(Good 次数 + Easy 次数) / 全部评分次数`，Hard 不计为成功。连续学习天数按系统本地日历日计算；若今天尚未学习而昨天学过，连续天数仍保留到今天结束。

## 学习会话、撤销与预测

学习页只保留当前页面最近一次成功评分的撤销入口，不做多级历史。仓储在事务内校验事件属于固定用户与 `recognition` 训练方式、事件确为 SQLite「最近提交」、当前记忆状态与 `afterJson` 一致；UUIDv7 字符串不用于判断同毫秒评分先后。首学撤销会删除对应记忆状态，复习撤销会恢复评分前快照并删除评分事件。成功后释放新词额度，统计、曲线、进度和首页队列通过统一刷新更新；失败整体回滚。外部评分或备份恢复会使旧撤销资格失效，页面会显示可读错误而不会静默覆盖。撤销后当前页面回到该词待揭晓状态，重新评分使用新事件编号。

本轮小结不写会话表，仅用当前页面成功生成的事件 ID 查询真实评分记录：撤销删除的事件不计入，Good/Easy 为成功，Hard 不计成功；0 次评分显示 `—` 而不是 100%。可以随时打开小结或提前结束返回，动态队列不显示固定任务总数，只显示已评次数与当前待学数。

统计页的「未来 7 天复习」使用 `LocalCalendar` 构造本地日界线，兼容固定 offset 测试与生产环境本地/DST 日历。`due <= now` 单独计入「现在待复习」；今天未来到下一次本地午夜，加上之后 6 个本地日，最后一天午夜及以后不算。只聚合当前用户 `recognition` 的 `memory_states`，每条记忆只算一次，不按词书关联重复、不受当前新词书过滤，孤立已学词仍计入。该区块是按当前安排估计，完成复习后会变化，不是总负担预测。

## 主题与外观

四套主题共用同一组语义令牌：墨绿奶白（默认）、海盐蓝、暖杏棕、石墨灰。每套均包含独立的浅色/深色画布、表面层级、正文与弱化文字、边框、主色、强调色及四档评分语义色。

设置页提供四张主题色卡和「跟随系统 / 浅色 / 深色」模式选项。设置保存在 `app_settings` 的 `theme_id` 与 `theme_mode` 键中，无需数据库 schema 迁移；保存成功后由应用级主题控制器立即广播，切换不会重建数据库、清空队列或移除当前学习词书。启动时在 `runApp` 前加载主题，避免先闪回默认主题。备份包含这两个键；旧备份缺少键时恢复为墨绿跟随系统，恢复含主题键的备份后会同步刷新全局主题。

## 自定义词库导入与导出

导入入口位于词书页，与学习备份恢复完全分开。选文件后先在后台 isolate 解析校验，再显示名称、总行数、有效词条、重复行、错误行和最多 5 条样例；确认前绝不写库。任何错误行都会默认禁止导入，不静默丢弃。20,000 条上限内的整书、新单词、新词义和词书关联在同一事务中写入；任一步失败全部回滚。单词按项目既有精确拼写区分大小写，词义按精确释义匹配；相同「单词 + 释义」复用已有词义、记忆状态和评分历史，导入自带的例句/音标不会覆盖已有共享词义。

| 格式 | 已验证内容 |
| --- | --- |
| CSV / TSV | UTF-8（可带 BOM）、CRLF/LF、引号内逗号/换行、双引号转义；首行支持 `word`/`spelling`/`单词` 与 `definition`/`meaning`/`释义` 等别名；无法可靠识别表头的多列表会要求列映射。 |
| TXT | 单列逐行按纯单词列表处理，可通过本地词典补全同一拼写的全部已有关联词义；没有本地释义的单词会明确列为错误。首行是表头或说明时可选“跳过首个单词”。 |
| JSON | 词条数组，或包含 `entries` 数组的对象；支持 `word`/`spelling`/`单词`、`definition`/`meaning`/`释义`、`phonetic(s)`/`音标`、`example`/`例句`。 |
| JSONL | 每行一个 JSON 对象，错误定位使用真实物理行号。 |
| `terms.dat` | 仅按与应用词库包相同的 JSONL 格式读取，不把任意 DAT 当文本猜测。 |
| Anki 纯文本 | 支持 `#separator`、`#html`、`#columns` 与 `#guid/#notetype/#deck/#tags column:N` 元数据列；支持 Front/Expression/单词与 Back/Meaning/释义别名。HTML 按显式标记清理标签、换行和常见实体，脚本/样式移除、媒体引用丢弃并提示；纯媒体释义不能通过。 |
| Quizlet 文本 | 可在导入页直接粘贴，自动识别分隔符，也可明确选择 Tab/逗号/分号/竖线/冒号/空格或纯单词模式，后续走同一预览确认管线。 |

限制固定为：文件 10 MB、最多 20,000 个词条；单词 128、释义 2,000、音标 200、例句 4,000 个 Unicode 字符。仅接受 UTF-8；UTF-16 BOM、非法 UTF-8、NUL 等非文本控制字符会明确报错，不做静默替换。列映射会拒绝单词与释义同列、越界列和已识别的 GUID/标签/牌组等元数据列。

单本词书可导出 CSV 或 JSON：CSV 带 UTF-8 BOM，字段按逗号、引号、换行规则转义；JSON 保留词书名称与完整词条。导出不包含学习进度、评分历史或设置。导入页可保存标准 CSV/JSON 模板。

当前**不直接支持** APKG、ZIP、XML、MDX、加密词典包、Anki 高级卡片/媒体/复习记录或 Quizlet API 抓词；应用会给出明确转换提示，不根据文件内容猜测格式。Anki 请导出 Notes in Plain Text，Quizlet 使用词语/定义文本，其他软件优先导出 CSV/TSV/TXT；欧路、有道、百词斩、墨墨等未取得统一可验证私有格式的软件不宣称全量兼容。

## FSRS 调度与记忆曲线

调度封装位于 `lib/domain/fsrs_engine.dart`，实际复习日期由 `fsrs 2.0.1` 的调度器计算。

| 配置 | 固定值 |
| --- | --- |
| 算法 | FSRS-6 |
| 目标保持率 | 0.90 |
| 新词学习步骤 | 1 分钟、10 分钟 |
| 重学步骤 | 10 分钟 |
| 最大间隔 | 36500 天 |
| 随机扰动 | 关闭，保证相同输入可复现 |
| 版本标识 | `fsrs-6/2.0.1/retention-0.90/fuzz-off` |
| 训练方式 | `recognition` |
| 时间精度 | UTC 毫秒 |

使用包内固定的 21 个默认模型参数，按顺序为：

```text
[0.2172, 1.1771, 3.2602, 16.1507, 7.0114, 0.57, 2.0966,
 0.0069, 1.5261, 0.112, 1.0178, 1.849, 0.1133, 0.3127,
 2.2934, 0.2191, 3.0004, 0.7536, 0.3332, 0.1437, 0.2]
```

完整配置快照包含参数、目标保持率、学习与重学步骤、最大间隔和扰动开关，随每条记忆状态保存到 `schedulerConfigJson`。恢复时必须与当前配置精确匹配；JSON 对象键顺序可以不同，未知版本或不同参数会被拒绝。

评分时间经 `core/clock.dart` 统一归一化为 UTC 毫秒，再用于计算和落库；界面显示本地时间，日统计使用 `core/local_calendar.dart`。若系统时间倒退，学习页会提示检查系统时间。四档间隔预测不会修改原卡片。

界面中的「艾宾浩斯记忆曲线」用于说明遗忘与复习强化趋势，**数值来自 FSRS 连续时间模型估计，不是艾宾浩斯实验数据，也不是对用户记忆的实测结果**。图中展示该词义最近最多 6 次评分：

- 实线表示已发生学习阶段的模型估计，未来部分使用虚线。
- 另一条虚线表示从图中第一次评分开始、假设此后未再复习的参考趋势。
- 水平参考线为 90%，当前保持率也按模型估计显示。
- 曲线只负责展示；实际下次复习时间仍由原包的调度计算决定。

## 数据模型

原生平台数据库由 `drift_flutter` 放置在平台应用文档目录，文件名为 `lexi_loop.sqlite`，数据库 schema 版本为 **1**，外键检查已启用。内部固定用户为 `local-user`。

| 表 | 主要内容与约束 |
| --- | --- |
| `words` | 单词 ID 与唯一拼写。数据库列名为 `text`，Dart 和备份字段名为 `spelling`。 |
| `word_senses` | 词义 ID、关联单词、中文释义、可空例句、可空音标文本。数据结构支持一词多义；考试词义没有提供例句。 |
| `wordbooks` | 词书 ID、名称、是否内置。 |
| `wordbook_entries` | 词书与词义的多对多关联，联合主键为词书 ID 与词义 ID。 |
| `memory_states` | 联合主键为用户、词义、训练方式；保存 FSRS 阶段、步骤、稳定度、难度、到期时间、上次评分时间、调度版本和完整配置快照。 |
| `review_events` | 每次评分一行，UUIDv7 为主键；保存用户、词义、训练方式、真实评分时间、评分档位、调度版本、前后卡片快照和可空作答耗时。 |
| `app_settings` | 键值设置，包括初始化版本、每日新词目标、可选学习词书 `active_wordbook_id`、`theme_id`、`theme_mode`、保持率、调度版本与配置。 |

首次初始化在事务中写入示例词条、默认词书和设置，并从随应用分发的 JSONL 文件幂等安装考试词库。已安装的旧版本在下次启动时新增考试词书，原有词义、学习状态、设置与评分历史均予以保留。旧版 JSON 备份恢复时会在同一事务中补齐内置考试词书。不同词书中的同一拼写和中文释义共用一个词义记录及记忆进度。评分时，记忆状态更新和事件写入处于同一事务，任一步失败会整体回滚。同一事件 ID 的合法重试返回已有结果，不重复推进记忆状态；重复 ID 被用于不同评分、陈旧候选或未到期卡片会被拒绝。

考试词库随包数据位于 `assets/wordbooks/`，来源修订和完整 MIT 许可文本保存在每份 `*-ATTRIBUTION.txt`。四份 JSONL 已与用户提供的原压缩包内 `terms.dat` 逐字节核对，并通过包内清单的 SHA-256 校验。应用不需要网络、数据库结构迁移或额外运行依赖；首次离线导入通过事务批量写入，并缓存解析后的词条供后续数据库实例复用。

## 备份格式与恢复

备份是 UTF-8 JSON，通过设置页的原生文件选择器保存。它包含全部内容、学习状态、评分历史与设置，属于完整数据快照。

| 顶层字段 | 格式 |
| --- | --- |
| `format` | 固定字符串 `lexi_loop_backup` |
| `schemaVersion` | 整数 `1` |
| `exportedAt` | UTC、毫秒精度的 ISO 8601 时间字符串 |
| `words` | 单词记录数组，拼写字段为 `spelling` |
| `wordSenses` | 词义记录数组 |
| `wordbooks` | 词书记录数组 |
| `wordbookEntries` | 词书与词义关联数组 |
| `memoryStates` | 记忆状态数组 |
| `reviewEvents` | 评分事件数组 |
| `appSettings` | 设置数组 |

记录字段使用 camelCase。卡片快照 `beforeJson`、`afterJson` 是 JSON 字符串，严格包含 `cardId`、`state`、`step`、`stability`、`difficulty`、`due`、`lastReview` 七个字段；其中时间保存为 UTC Unix 毫秒整数，未学习卡片允许 `lastReview` 为空。

恢复前会验证格式、版本、时间、字段类型、主键与唯一键、外键、支持的用户和训练方式、调度配置及卡片状态语义，并逐条重算评分结果，检查历史连续性、时间递增和最新快照与当前状态的一致性。文件可带 UTF-8 BOM；不兼容或损坏的备份会给出错误。

**恢复会替换本机自建内容与进度，不合并学习记录。** 应用内置的四本考试词书由受检数据包恢复后重新补齐，恢复文件无须包含词库数据。用户在界面确认后，程序先完成校验，再在单个事务中清空并重写用户数据表，随后确保应用内置词库可用。校验失败不动数据库；写入或词库补齐中途失败会回滚，保留恢复前数据。完成后刷新界面、每日目标与全局主题。恢复文件中的学习词书选择必须引用存在的词书，或恢复时会补齐的内置考试词书；无此设置的旧备份恢复为“全部词书”；缺少 `theme_id`/`theme_mode` 的旧备份恢复为墨绿跟随系统。

## 开发命令

在项目根目录执行。当前 Windows 工作区使用便携 SDK `.tools/flutter`，没有修改系统 PATH。该目录是本地工具，其他电脑需自行准备兼容 SDK；不要假定项目拷贝中一定包含 SDK。

$flutterExe = Join-Path $PWD '.tools/flutter/bin/flutter.bat'

## Dev 自动构建与发布

仓库为 `AutumnNazi/lexi-loop`，开发分支为 `dev`。工作流位于 `.github/workflows/dev-release.yml`：每次推送到 `dev` 自动检查、测试、构建；向 `dev` 或 `main` 的 PR 只做检查和测试；也可手动触发。后来的同分支提交会取消尚未完成的旧运行。

流程固定使用 Flutter 3.50.1，按 lockfile 安装依赖并生成 Drift 代码。检查与测试通过后并行构建 Windows、Android、macOS、iOS，四项成功后才创建带运行编号的 GitHub 预发布版本，版本对应明确的提交，不覆盖已有发布。构建产物也保留为 Actions artifacts 14 天。

## 当前边界

- 无账号、鉴权、多用户界面、云同步、远程 AI 或应用业务网络请求；备份由用户自行保管和转移。
- 无发音播放、录音、TTS 或第三方音频资源。
- 内置四本基于 ECDICT 的考试词库及 24 个原创示例词条，内置词书只读，不提供官方大纲核对或商业词库。自建词书可编辑；外部词库可通过 CSV/TSV/TXT/JSON/JSONL、Anki 纯文本、Quizlet 粘贴和词库包同款 JSONL `terms.dat` 导入。
- 不直接解码 APKG、ZIP、XML、MDX、加密词典包、Anki 高级卡片/媒体/复习记录或 Quizlet API；遇到这些格式会提示先在原软件导出纯文本。
- 调度训练方式仅为 `recognition`。拼写练习不创建记忆状态、不写评分记录、不参与 FSRS，离开页面后本轮成绩不持久保存。
- 目标保持率和 FSRS 参数固定，未提供个人参数训练、参数编辑或跨调度版本迁移。
- 备份目前只支持本项目版本 1 的完整快照，恢复采用替换方式，未实现增量合并、跨版本迁移或加密。
- 到期刷新在应用运行或恢复前台时生效，未实现系统后台提醒与推送通知。
- 当前目标平台为 Windows、macOS、Android、iOS；未提供 Web、Linux 平台工程和验证结果。
- 本轮撤销、本轮小结、未来 7 天预测与快捷键改动已完成本地自动化与中枢独立检查，但尚未提交、未触发四端构建；真机键盘映射、系统输入法/弹窗焦点和移动端深色系统栏仍需在对应设备上验收。
- 原生文件选择/保存、真实移动端深色系统栏与四端文件交互仍需在对应设备上验收；当前截图是 Widget 渲染结果。
